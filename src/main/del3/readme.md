### Complex Number Class

Dette prosjektet inneholder en Python-implementasjon av komplekse tall med støtte for utskrift, representasjon, og grunnleggende operasjoner. Klassen Complex tilbyr metoder for realdel, imaginærdel, addisjon, subtraksjon, multiplikasjon og divisjon. Det følger også med en testfil som verifiserer alle metodene.
